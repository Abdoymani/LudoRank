# إزاي تجرّب

## المتطلبات

- Flutter **3.44 أو أحدث** (مجرَّب على 3.47 stable). اكتب `flutter --version` وانت تعرف.
- Android Studio أو أي SDK لأندرويد عشان تشغّل على موبايل أو محاكي.

## 1. الاختبارات الأوتوماتيك

```bash
flutter pub get
flutter test
```

لازم يطلعلك **All tests passed**. لو اختبار واحد فشل، شغّله لوحده:

```bash
flutter test test/features/ludo_game/engine_regressions_test.dart
```

| الملف | بيختبر إيه |
| --- | --- |
| `test/ludo_game_engine_test.dart` | قواعد اللعبة كلها |
| `test/features/ludo_game/engine_regressions_test.dart` | باج خانة 51 + قاعدة الثلاث ستات |
| `test/core/database/*` | الجداول، الفهارس، المايجريشن |
| `test/features/tournaments/...` | حالة البطولة، الترتيب، إلغاء المباراة |
| `test/features/matches/...` | تشغيل المباراة وحفظها واسترجاعها |

وكمان:

```bash
flutter analyze   # المفروض ما يطلعش غير infos بتاعة material.dart deprecated
```

## 2. التجربة على الموبايل

```bash
flutter run                     # موبايل متوصّل بـ USB أو محاكي
flutter build apk --release     # APK في build/app/outputs/flutter-apk/
```

> ⚠️ **لو عندك بيانات قديمة على الموبايل:** نزّل الـ APK الجديد **فوق** القديم من غير ما تمسحه، عشان تتأكد إن الـ migration بتنقل البيانات صح.
> لو البيانات مهمة، جرّب الأول على موبايل تاني أو على نسخة منها.

## 3. قايمة التجربة اليدوية

- [ ] **منع التكرار:** اعمل بطولة وضيف لاعبين. افتح "إضافة لاعبين" تاني: اللي اتضافوا قبل كده ما يظهروش.
- [ ] **حالة البطولة:** اعمل أول مباراة، البطولة تتحول لـ"جارية".
- [ ] **رقم المباراة:** المباريات تظهر "مباراة رقم 1"، "مباراة رقم 2"…
- [ ] **إلغاء:** دوس "إلغاء" على مباراة، يطلعلك سؤال تأكيد، وبعدها المباراة تظهر ملغية وما تتحسبش في الترتيب.
- [ ] **إنهاء البطولة:** وفيه مباراة شغالة لازم يرفض. لما كل المباريات تخلص أو تتلغي يوافق، وبعدها زرار "إضافة لاعبين" يتقفل.
- [ ] **الحفظ:** اخرج من مباراة شغالة وادخل تاني بـ "استكمال المباراة"، لازم ترجع من نفس المكان.
- [ ] **الترقية (migration):** على موبايل عليه النسخة القديمة وفيه بيانات، نزّل الجديدة فوقها: البطولات والمباريات القديمة لازم تفضل موجودة وتاخد أرقام.
